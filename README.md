# whispryn
Whispryn is an edge AI system that recognizes acoustic events using TinyML and transforms them into intelligent robotic actions.
## Platform Choice
We use Raspberry Pi 5 because our WHISPRYN project requires microphone input, audio processing, machine learning and servo control. Raspberry Pi provides Linux, Python support and enough processing power and memory for these tasks. Although ESP32 is cheaper and consumes less power, Raspberry Pi is more suitable for our current project requirements.
